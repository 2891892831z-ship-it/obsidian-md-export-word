# 迁移检查清单

在新电脑部署后，按顺序勾选。

## 基础环境

- [ ] Windows 10/11 x64，或 Obsidian 1.7.2 支持的 macOS；
- [ ] macOS 已确认 `uname -m` 为 `arm64` 或 `x86_64`；
- [ ] Obsidian 1.7.2+；
- [ ] Python 3.10+；
- [ ] Microsoft Word 可正常打开 `.docx`；
- [ ] 若用引用：Zotero 已启动；
- [ ] 若用引用：Better BibTeX 已启用。

## 插件

- [ ] BRAT 已安装并启用；
- [ ] 已添加正确的 GitHub 仓库；
- [ ] MD Export Word 已启用；
- [ ] 运行时平台保持“自动检测”，或已明确选择正确架构；
- [ ] “Install or repair runtime”执行成功；
- [ ] “Check runtime”自检通过。

## 功能回归

- [ ] 普通中文正文；
- [ ] 英文和数字字体；
- [ ] `CO₂`、`H₂`、`δ¹³C` 真实上下标；
- [ ] 一个带编号公式；
- [ ] 一个两列公式编号结构；
- [ ] 一张本地图片和图题；
- [ ] 一个 Markdown 表格和表题；
- [ ] 中文“注：”；
- [ ] 英文“Note:”；
- [ ] 一个已存在 Zotero citekey；
- [ ] 一个兼容模式缺失 citekey；
- [ ] Zotero Refresh 成功；
- [ ] 自定义模板出现在模板列表；
- [ ] 输出 Word 位于 Markdown 同目录；
- [ ] 成功时无冗余日志，预期失败时生成失败日志；
- [ ] 导出成功后由 Word 或系统默认 `.docx` 程序自动打开。

## 最终确认

- [ ] Word 中无重复题目；
- [ ] 图表编号连续；
- [ ] 公式编号连续；
- [ ] 引文前无异常空格；
- [ ] 参考文献未缺失；
- [ ] 图片使用原始分辨率；
- [ ] 日志无阻断错误。
