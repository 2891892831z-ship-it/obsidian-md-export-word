# 格式与模板

## 模板与格式参数的关系

Word 模板负责：

- 页面和节设置；
- Word 样式基础；
- 页眉页脚；
- 默认字体和编号定义；
- 期刊或学校已有的固定结构。

导出对话框负责：

- 正文中英文字体；
- 字号、行距、首行缩进；
- 标题层级字号；
- 表格、图表题、图表注、公式字号；
- 页边距；
- 本次使用的模板。

当二者冲突时，导出器的明确格式参数优先；未明确处理的样式继承 Word 模板。

## 用户模板目录

自定义模板放在：

```text
<知识库>\.obsidian\plugins\md-export-word\templates
```

插件第一次安装运行时，会把内置模板复制到这里。后续“安装或修复运行时”
只更新 `runtime`，不会覆盖 `templates`。

## 新建期刊模板

1. 复制最接近的 `.docx`；
2. 改名，例如 `天然气地球科学.docx`；
3. 用 Word 打开副本；
4. 修改页面、样式、页眉页脚等；
5. 删除文档中的示例正文，只保留样式；
6. 保存并关闭 Word；
7. 确认同目录没有 `~$` 开头的临时文件；
8. 重新打开导出对话框选择该模板；
9. 导出一篇包含标题、正文、公式、表格、图片和引文的测试文档；
10. 查看自检日志并人工浏览。

## 建立格式预设

在格式对话框中：

1. 选择模板；
2. 设置字体、字号、行距等；
3. 输入预设名称；
4. 勾选保存；
5. 导出。

以后导出其他 Markdown 时可直接选择该预设。预设保存在插件 `data.json`，
不是写进 Markdown，因此不会污染论文正文。

## 模板版本管理

建议把正式模板也提交到本仓库的：

```text
runtime\Word-Template
```

每次模板有实质变化：

1. 修改文件名或更新 CHANGELOG；
2. 增加插件补丁版本；
3. 重新构建运行时 ZIP；
4. 用代表性 Markdown 做回归测试；
5. 发布同版本 Release。

个人试验模板只放用户 `templates` 目录，不要直接发布。
