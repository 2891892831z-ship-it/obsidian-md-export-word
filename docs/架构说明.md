# 架构说明

## 总览

```text
Obsidian 当前 Markdown
        │
        ▼
main.js（模式、模板、格式对话框）
        │
        ▼
系统识别与私有 Python 入口
        │
        ├── Windows x64
        ├── macOS Apple Silicon
        └── macOS Intel
        │
        ▼
Python 预检 ── Better BibTeX（可选/严格）
        │  实时 JSON 进度事件
        ├──────────────────────► Obsidian 进度窗口
        │
        ▼
Pandoc + pandoc-crossref + Lua filters
        │
        ▼
OOXML 后处理与自动检查
        │
        ▼
Word（成功）/ 失败日志（仅错误）
```

## BRAT 边界

标准 Obsidian 插件资产只有：

```text
main.js
manifest.json
styles.css
```

因此 Python、Lua、模板和大型二进制必须作为额外 Release 资产交付：

```text
md-export-word-runtime-windows-x64.zip
md-export-word-runtime-macos-arm64.zip
md-export-word-runtime-macos-x64.zip
SHA256SUMS-<平台>.txt
```

插件版本和运行时版本相同。GitHub Actions 在发布时把实际
`owner/repository` 写入 `main.js`，所以正式 BRAT 用户不需要手工配置下载
地址。自建分支仍可在插件设置中覆盖仓库地址。

插件读取 Electron/Node 的 `process.platform` 与 `process.arch`：

| 识别结果 | 目标 |
| --- | --- |
| `win32/x64` | `windows-x64` |
| `darwin/arm64` | `macos-arm64` |
| `darwin/x64` | `macos-x64` |

Apple Silicon 上运行 Intel 版 Obsidian 时，Electron 会报告 `x64`，因此自动
选择 Intel 运行时。原生 Apple Silicon Obsidian 自动选择 arm64。

## 安装目录

```text
<知识库>/.obsidian/plugins/md-export-word/
├── main.js
├── manifest.json
├── styles.css
├── data.json
├── templates\                 # 用户模板，升级不覆盖
└── runtime\
    ├── .venv\
    ├── Pandoc&pandoc-crossref\
    ├── Word-Template\         # 内置模板原件
    ├── scripts\
    ├── zotero.lua
    └── runtime-manifest.json
```

Windows 中路径分隔符显示为 `\`，macOS 显示为 `/`；插件使用 Node 的
`path` API 生成路径，不在代码中硬编码用户目录。

## 版本固定

`runtime/runtime-manifest.json` 固定：

- Pandoc 3.8.2.1；
- pandoc-crossref 0.3.22；
- lxml 6.0.2；
- Python 最低 3.10。

pandoc-crossref 必须与 Pandoc 构建版本匹配，不能只升级其中一个。

## 安全边界

- 只处理用户主动选择的当前 Markdown；
- 输出到源文件目录；
- 不修改 Markdown；
- 不写入 Zotero 数据库；
- Better BibTeX 通信只走 `127.0.0.1`；
- 下载只来自设置中的 GitHub 仓库同版本 Release；
- 运行时安装在插件目录，不修改系统 PATH；
- Python 依赖安装在插件私有虚拟环境。
- macOS 可执行权限只授予当前运行时内的脚本、Pandoc 和 pandoc-crossref。

## 进度与日志

Python 通过带固定前缀的单行 JSON 事件报告真实阶段和百分比。插件逐行解析
事件并把普通标准输出同步到进度窗口。`PYTHONUNBUFFERED=1` 和 Python
行缓冲确保长文档处理时不会等到进程结束才看到输出。

成功导出不写日志文件；结构化自检摘要显示在窗口。失败时 Python 写入错误
类型、命令和 traceback，插件再追加已捕获的完整进程输出。

## 可恢复性

运行时安装使用临时目录和备份目录完成替换。安装失败时插件报告错误，不会
把用户模板目录作为运行时删除目标。正式论文仍应保留 Git、云盘或其他独立
备份。

## 跨平台发布

GitHub Actions 使用三个独立 runner：

- `windows-latest`：测试和构建 Windows x64；
- `macos-15`：测试和构建 Apple Silicon arm64；
- `macos-15-intel`：测试和构建 Intel x64。

每个平台都先运行同一份 `scripts/smoke-runtime.py`，验证默认文件名、自定义
文件名、同名时间戳、不覆盖已有 Word、成功不留日志和失败生成日志，再打包
平台对应的 Pandoc/pandoc-crossref。最终 Release 只有在三组任务全部通过后
才创建。
